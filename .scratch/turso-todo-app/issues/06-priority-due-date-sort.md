# 06: 우선순위/마감일 기준 정렬 확장

**What to build:** 목록이 "미완료 우선 → 우선순위 높은순 → 마감일 빠른순 → 동률이면 생성순"으로 항상 정렬되어 보이게 한다.

**Blocked by:** 02, 04

**Status:** ready-for-agent

- [ ] `lib/todos.ts`의 `listTodos()`가 완료 여부를 1차 기준으로 정렬한다 (미완료가 위).
- [ ] 같은 완료 상태 안에서는 우선순위가 높은 항목이 먼저 온다.
- [ ] 우선순위가 같으면 마감일이 빠른 항목(마감일 없는 항목보다 우선)이 먼저 온다.
- [ ] 모든 기준이 동률이면 먼저 생성된 항목이 먼저 온다.
- [ ] 정렬을 사용자가 바꿀 수 있는 UI 컨트롤은 추가하지 않는다 (고정 규칙).
- [ ] 다양한 완료 상태/우선순위/마감일 조합에 대해 `listTodos()`의 반환 순서가 로컬 libSQL 테스트 DB에 대해 테스트된다 (모킹 없이).
