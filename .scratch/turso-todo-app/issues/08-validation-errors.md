# 08: 입력 검증 에러 표시

**What to build:** 추가/수정 폼에 잘못된 입력(빈 제목, 잘못된 우선순위/마감일 형식)을 제출했을 때 사용자가 알아볼 수 있는 에러 메시지를 보여준다.

**Blocked by:** 01, 05

**Status:** ready-for-agent

- [ ] 제목을 비워둔 채(또는 공백만 입력해) 추가/수정을 시도하면 에러 메시지가 표시되고 저장되지 않는다.
- [ ] 우선순위에 허용되지 않은 값을 보내면 에러로 처리된다 (UI는 드롭다운이라 정상 흐름에서는 발생하지 않지만 Server Action 레벨에서 방어된다).
- [ ] 마감일에 올바르지 않은 형식의 값을 보내면 에러로 처리된다.
- [ ] 에러 발생 시 사용자가 입력했던 다른 필드 값은 폼에서 유지된다.
- [ ] zod 검증 규칙(제목 필수, 우선순위 enum, 마감일 형식)이 Server Action 레벨에서 테스트된다.
