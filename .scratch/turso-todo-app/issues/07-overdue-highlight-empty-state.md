**Blocked by:** 04

**Status:** done

- [x] 마감일이 오늘보다 이전이고 완료되지 않은 항목은 목록에서 시각적으로 강조 표시된다 (예: 색상/아이콘 등).

## Comments

- `app/page.tsx`의 `TodoList()`에 `isOverdue(todo, todayStr)` 헬퍼를 추가해, `!todo.completed && todo.dueDate && todo.dueDate < todayStr`일 때만 마감일 텍스트에 강조 스타일(`text-red-600`/`dark:text-red-400`, `font-semibold`)과 "(지남)" 라벨을 적용했다. 완료된 항목, `dueDate`가 없는 항목은 조건에 걸리지 않아 기존 스타일 그대로 렌더링된다.
- 빈 상태 안내 문구("아직 할 일이 없습니다.")는 ticket 01에서 이미 구현되어 있었고, 조건(`items.length === 0`)을 그대로 재확인함 — 이번 티켓에서 추가 변경 없음.
- 검증:
  - `npm test` (9/9 통과), `npm run lint`, `npm run build` 모두 통과.
  - `npm run dev`로 로컬 서버를 띄운 뒤, 렌더된 홈페이지 HTML에서 추가 폼의 `$ACTION_ID_*` 히든 필드를 읽어 `curl -F`로 실제 서버 액션에 과거 마감일(`2026-11-01`, 오늘은 2026-11-18)을 가진 미완료 할 일을 생성 — 응답 HTML에 `마감일: 2026-11-01 (지남)`이 `text-red-600`(강조) 클래스로 렌더링됨을 확인.
  - 테스트용 항목은 `lib/todos.ts`의 `deleteTodo`를 직접 호출하는 임시 스크립트로 삭제하고, 재요청으로 목록이 다시 비어 "아직 할 일이 없습니다."가 표시됨을 확인한 뒤 dev 서버 종료.
