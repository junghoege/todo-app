# 07: 마감일 지난 항목 강조 + 빈 목록 안내

**What to build:** 마감일이 지난 미완료 항목을 시각적으로 구분해서 보여주고, 할 일이 하나도 없을 때는 안내 문구를 보여준다.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 마감일이 오늘보다 이전이고 완료되지 않은 항목은 목록에서 시각적으로 강조 표시된다 (예: 색상/아이콘 등).
- [ ] 완료된 항목이나 마감일이 없는 항목은 이 강조가 적용되지 않는다.
- [ ] 할 일이 하나도 없을 때는 빈 상태 안내 문구가 표시된다.
